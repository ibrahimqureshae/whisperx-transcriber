Four steps, no terminal.

Unzip it, run it, and the first launch installs the speech engine for your GPU or CPU. After that, this is the whole workflow.

01

Drop your files

An interview, a stack of lectures, or a whole folder. Each file shows its waveform right away.

02

Press Transcribe

The queue runs back to back. Seven dots per file track each step, and the language is detected for you.

03

Name the speakers

Every voice gets a coloured lane. Type a name once and it replaces the label everywhere, exports included.

04

Find and export

Search any word, check the doubtful ones, then export SRT, VTT, TXT, JSON and more in one click.

Questions

Is it really offline?

Yes, after the first launch. The setup downloads the speech engine once, and each model downloads the first time you use it. From then on every transcription runs with the Wi-Fi off. Turn on Offline only in Settings and the app uses only the models already on your disk.

Do I need an NVIDIA GPU?

No. With an NVIDIA GPU and driver 560 or newer the app uses it and runs many times faster than real time. Without one it runs on the CPU; pick the small or base model for speed.

Windows says "Windows protected your PC".

That's SmartScreen reacting to an unsigned build. Click More info, then Run anyway. The app is open source, and code signing is on the roadmap.

Do I need Python or an account?

No. The setup wizard installs everything it needs, including Python if you don't have it. There is no account, token or sign-up anywhere.

How accurate is it?

It uses the same Whisper models as the WhisperX command line, so the quality matches it on the same model and settings. Words the model is unsure about are underlined so you can check them.
